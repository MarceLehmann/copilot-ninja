    Controllare una tabella alla ricerca di anomalieControllare una tabella alla ricerca di anomalie

    Prima che un'esportazione prosegua

    La situazione

    L'esportazione della contabilità va subito alla fiduciaria. Se ci sono righe doppie o campi vuoti, a occhio non lo vedi.

    Il taglio

    Prima

    «Controlla questa tabella.»

    Dopo

    Adattalo a te

    Nulla lascia il tuo browser.

    ad es. nome del foglio

    Prompt da copiare

    Obiettivo: Controlla la tabella allegata alla ricerca di anomalie. Non modificare nulla.

Contesto: È un'esportazione dal nostro sistema. La controllo prima di inoltrarla.

Fonte: Solo il file allegato, foglio [Foglio, ad es. nome del foglio]. Non usare conoscenze dal web.
Controlla questi punti:
1. Righe doppie.
2. Campi vuoti nelle colonne [Colonna A] e [Colonna B].
3. Valori che si discostano molto dal resto della colonna [Colonna C].
4. Date che non sono nel formato GG.MM.AAAA.

Aspettative: Una tabella con le colonne Numero di riga, Colonna ed Esito. Sotto, una frase che dice quante righe hai controllato. Se non puoi controllare qualcosa, scrivilo espressamente.

    Senza licenza aggiuntiva in Microsoft Copilot Chat, con caricamento di file. Senza il pulsante di copia: seleziona il testo e copialo con Ctrl+C.

    Come usarla

    1. Carica il file in Microsoft Copilot Chat.
    2. Inserisci foglio e nomi delle colonne dal tuo file e invia.
    3. Verifica due o tre risultati nel file originale prima di fidarti dell'elenco.

    Come riconoscere una buona risposta

    • Un elenco degli esiti con numero di riga, colonna ed esito.
    • Una frase che dice quante righe sono state controllate.
    • Un avviso esplicito se qualcosa non ha potuto essere controllato.

    La verifica

    Controlla un file con un doppione noto. Se manca nell'elenco degli esiti, l'elenco non è corretto.

    Limiti

    • Il caricamento dei file ha dei limiti. La pagina Microsoft consultata non indica cifre precise, quindi qui non compaiono.
    • Gli esiti sono indicazioni e non una revisione. Verifica due o tre risultati nel file originale prima di fidarti.
    • Copilot Chat (Basic) non ha accesso a Copilot in Excel. Microsoft 365 Copilot (Basic) offre senza add-on un accesso standard, che in caso di forte carico può essere limitato. Microsoft 365 Copilot (Premium) offre con l'add-on la piena portata e Priority Access. La denominazione nel prodotto mostra il tuo livello; licenza e configurazione del tenant determinano la disponibilità. Questa forma base lavora con un file caricato nella chat.
