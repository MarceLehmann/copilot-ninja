    Die SchriftprobeAgent-Anweisungen vor dem Test prüfen

    Bevor du einen Agent zum ersten Mal testest

    Die Lage

    Die Anweisungen deines Agents sind über Wochen gewachsen. Im Testchat eiert er herum, und du weisst nicht, welche Regel schuld ist.

    Der Schnitt

    Vorher

    «Sind meine Agent-Anweisungen gut?»

    Nachher

    Für dich anpassen

    Nichts verlässt deinen Browser.

    z. B. die Anweisungen deines Agents

    Prompt zum Kopieren

    Ziel: Prüfe die Agent-Anweisungen unten, bevor ich sie teste. Schreib sie nicht neu.

Erwartung: Prüfe diese Punkte und gib eine Tabelle mit Fundstelle, Problem und Vorschlag aus.
1. Widersprüche zwischen zwei Regeln.
2. Verweise auf Tools, Wissensquellen, Topics oder andere Agents. Liste alle auf, damit ich prüfe, ob sie im Agent wirklich eingerichtet sind.
3. Schritte ohne klaren Übergang zum nächsten Schritt.
4. Mehrdeutige Wörter wie «kurz», «manchmal» oder «wichtig», die ein Agent unterschiedlich auslegen kann.
5. Anweisungen, die die Darstellung von Quellenangaben oder Zitaten ändern oder unterdrücken.
6. Was der Agent tun soll, wenn er nicht weiterweiss. Fehlt das, sag es.
Am Ende: die drei Punkte, die ich zuerst beheben sollte.

Anweisungen:
[Anweisungen, z. B. die Anweisungen deines Agents]

    Ohne Zusatzlizenz in Microsoft Copilot Chat, für Anweisungen aus Copilot Studio oder Agent Builder. Ohne Kopierknopf: Text markieren und mit Strg+C kopieren.

    So nutzt du es

    1. Die Anweisungen aus deinem Agent kopieren, einfügen und in Microsoft Copilot Chat senden.
    2. Die Liste der Tools und Wissensquellen mit dem abgleichen, was im Agent wirklich eingerichtet ist.
    3. Die drei wichtigsten Punkte beheben und den Agent danach mit Nr. 18 prüfen.
    4. Änderungen einzeln einbauen und dazwischen testen. So rät es Microsoft für Anweisungen in Copilot Studio.

    Woran du eine gute Antwort erkennst

    • Eine Tabelle mit Fundstelle, Problem und Vorschlag.
    • Eine vollständige Liste aller erwähnten Tools und Wissensquellen.
    • Drei Punkte mit Vorrang am Ende.
    • Keine neu geschriebenen Anweisungen.

    Die Probe

    Zähle die bestandenen Testfragen aus Nr. 18 vor und nach der Korrektur.

    Grenzen

    • Laut Microsoft kann ein Agent Anweisungen zu Tools, Wissensquellen, Agents oder Topics nur befolgen, wenn sie im Agent eingerichtet sind. Punkt 2 im Prompt macht genau das sichtbar.
    • Microsoft rät, das Zitierformat in Copilot Studio nicht per Anweisung zu ändern oder zu unterdrücken. Punkt 5 findet solche Stellen.
    • Die Prüfung liest nur Text. Ob der Agent sich danach richtig verhält, zeigt erst der Test.
    • Interne Namen und Kontaktangaben in den Anweisungen nur einfügen, wenn eure internen Regeln das erlauben.
