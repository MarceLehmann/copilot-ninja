    Der EhrenkodexBetriebsblatt mit Abschaltkriterien

    Bevor du einen Agent für andere freigibst

    Die Lage

    Im Team laufen inzwischen mehrere Agents. Wer sie pflegt und wann einer abgeschaltet wird, weiss niemand genau.

    Der Schnitt

    Vorher

    «Dokumentiere meinen Agent.»

    Nachher

    Für dich anpassen

    Nichts verlässt deinen Browser.

    z. B. die Anweisungen deines Agents

    Text zum Kopieren

    Ziel: Erstelle aus den Agent-Anweisungen unten ein Betriebsblatt.

Quelle: Nur die Anweisungen. Fülle nur aus, was sich daraus ableiten lässt. Alles andere markierst du mit [FESTLEGEN].

Erwartung: Ein Betriebsblatt mit diesen Feldern:
- Name und Zweck in einem Satz
- Verantwortlich und Stellvertretung
- Zielgruppe und Kanal
- Wissensquellen, wer sie pflegt, letztes Prüfdatum
- Tools und Aktionen, und was sie verändern dürfen
- Testset und letzte Bestehensquote
- Geschätzter Verbrauch an Copilot Credits pro Monat und Verbrauchsgrenze
- Abschaltkriterien
- Nächstes Review-Datum
Schlag für das Feld Abschaltkriterien drei Kriterien vor, die zu diesem Agent passen, und begründe jedes in einem Satz.

Anweisungen:
[Anweisungen, z. B. die Anweisungen deines Agents]

    Ohne Zusatzlizenz in Microsoft Copilot Chat. Das Blatt ist eine Methode, keine Microsoft-Funktion. Ohne Kopierknopf: Text markieren und mit Strg+C kopieren.

    So nutzt du es

    1. Anweisungen einfügen und in Microsoft Copilot Chat senden.
    2. Jedes [FESTLEGEN] mit der verantwortlichen Person klären.
    3. Die Abschaltkriterien mit Zahlen versehen, zum Beispiel eine Bestehensquote aus Nr. 18, unter der der Agent pausiert.
    4. In Copilot Studio kannst du laut Microsoft im Power Platform Admin Center pro Agent eine monatliche Verbrauchsgrenze setzen. Trag sie ins Blatt ein.
    5. Das Review-Datum als Termin in den Kalender der verantwortlichen Person setzen.

    Woran du eine gute Antwort erkennst

    • Alle Felder des Blatts, ausgefüllt oder mit [FESTLEGEN] markiert.
    • Drei vorgeschlagene Abschaltkriterien mit Begründung.
    • Nichts, was nicht aus den Anweisungen ableitbar ist.

    Die Probe

    Zähle den Anteil eurer Agents mit ausgefülltem Betriebsblatt und die Agents ohne verantwortliche Person.

    Grenzen

    • Ein Blatt ohne Termin im Kalender ist Papier. Das Review-Datum gehört als Termin zur verantwortlichen Person.
    • Die Kriterien sind Vorschläge. Festlegen müsst ihr sie im Team.
    • Laut Microsoft werden Custom Agents bei 125 Prozent der vorausbezahlten Kapazität deaktiviert. Ein eigenes Abschaltkriterium greift idealerweise vorher.
