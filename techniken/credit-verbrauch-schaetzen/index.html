    Der Credit-KompassCredit-Verbrauch eines Agents vorher schätzen

    Bevor ein Agent live geht

    • Gürtel Brauner Gürtel, Stufe 6
    • Art Kata
    • Zugang Rechnen ohne Lizenz, Betrieb braucht Kapazität
    • Ausprobieren ca. 15 Min.

    Die Lage

    Die Geschäftsleitung fragt, was der neue Agent im Betrieb verbraucht. Du hast eine Vermutung, aber keine Rechnung.

    Der Schnitt

    Vorher

    «Was kostet mein Agent?»

    Nachher

    Für dich anpassen

    Nichts verlässt deinen Browser.

    z. B. Mitarbeitende im Innendienst
    z. B. eine Wissensquelle und zwei Tools
    z. B. die Anweisungen deines Agents

    Text zum Kopieren

    Ziel: Hilf mir, für meinen Agent die Ereignisse pro Gespräch zu schätzen. Seine Anweisungen stehen unten.

Kontext: Der Agent ist für [Zielgruppe, z. B. Mitarbeitende im Innendienst]. Er nutzt [Ausstattung, z. B. eine Wissensquelle und zwei Tools].

Erwartung:
1. Für ein typisches und für ein langes Gespräch: wie viele Antworten aus Wissensquellen (generativ), wie viele vordefinierte Antworten (klassisch) und wie viele Aktionen wie Tools oder Wechsel zwischen Topics und wie viele Schritte in Agent Flows zu erwarten sind.
2. Pro Zahl ein Satz Begründung.
3. Die Annahme, die das Ergebnis am stärksten verändert.
Kennzeichne alles als Schätzung. Rechne keine Preise.

Anweisungen:
[Anweisungen, z. B. die Anweisungen deines Agents]

    Rechnen ohne Lizenz, Betrieb braucht Kapazität. Ohne Kopierknopf: Text markieren und mit Strg+C kopieren.

    Der Kompass

    Raten laut Microsoft in Copilot Credits: Classic answer 1, Generative answer 2, Agent action 5, Tenant graph grounding 10, Agent-Flow-Aktion 0.13.

    Rechenbeispiel: 400 Gespräche im Monat mit je 3 Generative Answers und 1 Agent Action ergeben 400 mal 11, also 4'400 Copilot Credits. Erfundene Annahme zur Veranschaulichung.

    • Copilot Studio setzt die gekaufte Kapazität laut der Seite zur Lizenzierung monatlich durch, nicht genutzte Copilot Credits gehen nicht in den nächsten Monat über. Der Agent Usage Estimator schreibt dagegen, dass manche Käufe übertragbar sind. Massgebend ist dein Vertrag.
    • Bei 125 Prozent der vorausbezahlten Kapazität werden Custom Agents deaktiviert. Ein laufendes Gespräch wird nicht unterbrochen.
    • Ist die Kapazität aufgebraucht, starten keine neuen Agent Flows mehr. Der Agent selbst antwortet weiter.

    Laut Ratentabelle fallen für Mitarbeitende mit Microsoft-Copilot-Lizenz bei Classic answers, Generative answers, Agent actions, Tenant graph grounding und Agent-Flow-Aktionen keine Copilot Credits an, wenn der Agent mit ihrer angemeldeten Identität läuft. Bei Agent Flows gilt das nur für den Auslöser «When an agent calls the flow». Es gelten Fair-Use-Grenzen. Die Seite zur Lizenzierung nennt dagegen nur Classic answers, Generative answers und Graph Grounding ohne Verbrauch. Microsoft ist hier nicht einheitlich. Rechne im Zweifel ohne Haken.

    Quelle: Microsoft Learn: Billing rates and management (Copilot Studio), Microsoft Learn: Standard harness licensing (Copilot Studio), Microsoft Learn: Agent usage estimator (Copilot Studio), Stand 15.10.2026. Kein Preis pro Credit, Preise findest du bei Microsoft.

    So nutzt du es

    1. Anweisungen einfügen, Zielgruppe und Ausstattung beschreiben und in Microsoft Copilot Chat senden.
    2. Die Zahlen pro Gespräch in den Rechner auf dieser Seite übernehmen und die Gespräche pro Monat schätzen.
    3. Drei Fälle rechnen: wenig, mittel und viel Betrieb.
    4. Für eine genauere Schätzung bietet Microsoft den Agent Usage Estimator an.
    5. Nach dem ersten Monat den Verbrauch im Power Platform Admin Center mit deiner Schätzung vergleichen.

    Woran du eine gute Antwort erkennst

    • Zahlen für ein typisches und ein langes Gespräch.
    • Eine Begründung pro Zahl.
    • Die Annahme mit dem grössten Einfluss.
    • Keine Preise, nur Ereignisse.

    Die Probe

    Vergleiche deine Schätzung nach dem ersten Monat mit dem tatsächlichen Verbrauch. Die Abweichung zeigt, wie gut deine Annahmen über die Gespräche waren.

    Grenzen

    • Preise pro Copilot Credit nennt diese Seite nicht. Sie stehen bei Microsoft.
    • Die Raten stammen aus der Microsoft-Dokumentation und können sich ändern. Massgebend ist die verlinkte Quelle.
    • Für Agents, die im Agent Builder erstellt sind und kein Tenant Graph Grounding nutzen, fallen laut Microsoft für Generative Answers keine Credits an.
    • Agent Flows rechnet Microsoft separat ab: 13 Copilot Credits pro 100 Flow-Aktionen. Power Automate Cloud Flows laufen laut Microsoft über die Power-Automate-Lizenz und nicht über Copilot Credits.
    • Microsoft empfiehlt beim Agent Usage Estimator 10 bis 20 Prozent Reserve auf die Schätzung.
    • Die Schätzung ersetzt nicht den Blick auf den tatsächlichen Verbrauch.

    Quellen

    Microsoft Learn: Billing rates and management (Copilot Studio), Microsoft Learn: Standard harness licensing (Copilot Studio), Microsoft Learn: Agent usage estimator (Copilot Studio). Stand 15.10.2026.
