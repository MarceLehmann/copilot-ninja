    Der DolmetscherPower-Automate-Ausdrücke mit Erklärung

    Wenn ein Ausdruck nicht tut, was er soll

    Die Lage

    Der Flow soll das Datum aus dem Formular in Schweizer Zeit als TT.MM.JJJJ in die Mail schreiben. Die Ausdrücke aus Foren funktionieren nicht, und keiner ist erklärt.

    Der Schnitt

    Vorher

    «Gib mir einen Ausdruck für das Datum.»

    Nachher

    Für dich anpassen

    Nichts verlässt deinen Browser.

    z. B. das Datum aus dem Trigger in Schweizer Zeit als TT.MM.JJJJ ausgeben
    z. B. 2026-10-15T08:30:00Z

    Prompt zum Kopieren

    Ziel: Ich brauche einen Ausdruck für Power Automate.

Kontext: Der Ausdruck soll [Aufgabe, z. B. das Datum aus dem Trigger in Schweizer Zeit als TT.MM.JJJJ ausgeben]. Die Eingabe sieht so aus: [Beispielwert, z. B. 2026-10-15T08:30:00Z].

Quelle: Stütz dich auf die Referenz der Ausdrucksfunktionen auf learn.microsoft.com und nenne zu jeder verwendeten Funktion den Link.

Erwartung:
1. Der Ausdruck in einer Zeile zum Kopieren.
2. Eine Erklärung von innen nach aussen, eine Zeile pro Funktion.
3. Das erwartete Ergebnis für meinen Beispielwert.
4. Ein Randfall, an dem der Ausdruck scheitert, zum Beispiel ein leerer Wert, und wie ich ihn abfange.

    Ohne Zusatzlizenz in Microsoft Copilot Chat. Für den Flow gelten die Lizenzen von Power Automate. Ohne Kopierknopf: Text markieren und mit Strg+C kopieren.

    So nutzt du es

    1. Aufgabe und einen echten Beispielwert aus dem Flow-Verlauf eintragen, ohne Kundendaten.
    2. Senden und die verlinkten Funktionen in der Referenz nachlesen.
    3. Den Ausdruck zuerst in einem Test-Flow ausprobieren.
    4. Den Randfall bewusst auslösen und prüfen, ob dein Abfangen greift.

    Woran du eine gute Antwort erkennst

    • Ein Ausdruck in einer Zeile.
    • Eine Zeile Erklärung pro Funktion, von innen nach aussen.
    • Ein Link zur Referenz bei jeder Funktion.
    • Ein Randfall mit Lösung.

    Die Probe

    Miss die Zeit bis zum funktionierenden Ausdruck. Zähle danach pro Monat die Flow-Läufe, die an Ausdrucksfehlern scheitern.

    Grenzen

    • Laut Microsoft gilt die Referenz der Ausdrucksfunktionen für Azure Logic Apps und für Power Automate. Sie steht in der Dokumentation von Azure Logic Apps.
    • Bei Zeitzonen verweist die Referenz auf die Windows-Zeitzonennamen. Prüf das Ergebnis an einem Datum im Sommer und an einem im Winter.
    • Keine Verbindungsdaten, Schlüssel oder Kundendaten in den Prompt. Websuchanfragen sind laut Microsoft nicht vom Data Protection Addendum abgedeckt.
    • Ist die Websuche abgeschaltet, fehlen die Links. Dann schlägst du die Funktionen selbst nach.
    • Für den Flow selbst gelten die Lizenzen von Power Automate. Diese sind hier nicht geprüft.

    Quellen

    Microsoft Learn: Reference guide to functions in expressions for workflows in Azure Logic Apps and Power Automate, Microsoft Learn: Enterprise data protection in Microsoft Copilot and Microsoft Copilot Chat, Microsoft Learn: Manage Microsoft Copilot Chat. Stand 15.10.2026.
