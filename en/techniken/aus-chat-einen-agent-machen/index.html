    The ImprintTurn your best chat into an agent

    At the end of a chat that went really well

    The situation

    In one chat, after several corrections, everything finally worked. Next week you start from zero again and explain everything once more.

    The cut

    Before

    “Remember how I want this done.”

    After

    Text to copy

    Goal: This conversation worked well. Turn it into three clearly separated sections for an agent.

Source: Only this chat history.

Expectations:
# Name
At most 30 characters.
# Description
At most 1000 characters. Describe its purpose and tasks to help the model and users find the agent.
# Instructions
At most 8000 characters, in Markdown with the subheadings Purpose, Process, Tone and format, and Limits. Each process step has a goal, action and transition to the next step. Turn my corrections into fixed rules. Leave out details that only applied to this case and list them separately after the three sections.

    No add-on license with Agent Builder, instructions and public websites only. Without a copy button: select the text and copy it with Ctrl+C.

    How to use it

    1. At the end of a successful chat in Microsoft Copilot Chat, paste the text and send it.
    2. Read the list of details and add anything that is a fixed rule after all.
    3. In Agent Builder, create a new agent and use “Skip to configure” to go straight to the configuration.
    4. In the “Configure” tab, paste the name into “Name” (at most 30 characters), the description into “Description” (at most 1000 characters) and only the instructions into “Instructions” (at most 8000 characters). “Knowledge” and “Starter Prompts” are separate fields.
    5. Try the agent in the “Try it” tab with three real tasks.
    6. Then check the instructions with No. 17.

    How to spot a good answer

    • Three separate sections: Name, Description and Instructions with purpose, process, tone and format, and limits.
    • Each process step with goal, action and transition.
    • Your corrections as fixed rules.
    • A separate list of details that only applied to this case.

    The check

    For one week, count how often you type the same explanation into a new chat. Then count for one week with the agent.

    Limits

    • According to Microsoft, you can use Agent Builder for free without an add-on license as long as the agent only relies on instructions and web knowledge.
    • If the agent should access SharePoint or other company data, Microsoft says it is billed by consumption. For Microsoft Copilot Chat users this is off by default.
    • The menu names come from the English documentation. Your interface may name them differently.
    • One chat history shows one case. Check the agent with other cases before you share it.

    Sources

    Microsoft Learn: Choose between Agent Builder and Copilot Studio to build your agent, Microsoft Learn: Agents for Microsoft Copilot Chat, Microsoft Learn: Build agents in Agent Builder, Microsoft Learn: Write effective instructions for declarative agents. As of October 15, 2026.
