    The Code of HonorOperations sheet with shutdown criteria

    Before you release an agent to others

    The situation

    Several agents are now running in the team. Nobody knows exactly who maintains them and when one gets shut down.

    The cut

    Before

    “Document my agent.”

    After

    Make it yours

    Nothing leaves your browser.

    e.g. your agent's instructions

    Text to copy

    Goal: Create an operations sheet from the agent instructions below.

Source: Only the instructions. Fill in only what can be derived from them. Mark everything else with [TO DEFINE].

Expectations: An operations sheet with these fields:
- Name and purpose in one sentence
- Owner and deputy
- Audience and channel
- Knowledge sources, who maintains them, last check date
- Tools and actions, and what they may change
- Test set and latest pass rate
- Estimated consumption of Copilot Credits per month and consumption limit
- Shutdown criteria
- Next review date
For the shutdown criteria field, suggest three criteria that fit this agent, and justify each in one sentence.

Instructions:
[Agent instructions, e.g. your agent's instructions]

    No add-on license in Microsoft Copilot Chat. The sheet is a method, not a Microsoft feature. Without a copy button: select the text and copy it with Ctrl+C.

    How to use it

    1. Paste the instructions and send them in Microsoft Copilot Chat.
    2. Clarify every [TO DEFINE] with the responsible person.
    3. Add numbers to the shutdown criteria, for example a pass rate from No. 18 below which the agent is paused.
    4. According to Microsoft, for Copilot Studio you can set a monthly consumption limit per agent in the Power Platform admin center. Enter it in the sheet.
    5. Put the review date as an appointment in the responsible person's calendar.

    How to spot a good answer

    • All fields of the sheet, filled in or marked with [TO DEFINE].
    • Three suggested shutdown criteria with reasons.
    • Nothing that cannot be derived from the instructions.

    The check

    Count the share of your agents with a completed operations sheet and the agents without a responsible person.

    Limits

    • A sheet without an appointment in the calendar is just paper. The review date belongs in the responsible person's calendar.
    • The criteria are suggestions. You have to decide on them as a team.
    • According to Microsoft, custom agents are disabled at 125 percent of the prepaid capacity. Ideally, your own shutdown criterion kicks in earlier.

    Sources

    Microsoft Learn: Billing rates and management (Copilot Studio), Microsoft Learn: Overview of Microsoft Copilot Chat, Microsoft Learn: Agent usage estimator (Copilot Studio). As of October 15, 2026.
