    The InterpreterPower Automate expressions with explanations

    When an expression doesn't do what it should

    The situation

    The flow should write the date from the form into the email in Swiss time as DD.MM.YYYY. The expressions from forums don't work, and none of them is explained.

    The cut

    Before

    “Give me an expression for the date.”

    After

    Make it yours

    Nothing leaves your browser.

    e.g. output the date from the trigger in Swiss time as DD.MM.YYYY
    e.g. 2026-10-15T08:30:00Z

    Prompt to copy

    Goal: I need an expression for Power Automate.

Context: The expression should [Task, e.g. output the date from the trigger in Swiss time as DD.MM.YYYY]. The input looks like this: [Sample value, e.g. 2026-10-15T08:30:00Z].

Source: Base your answer on the expression functions reference on learn.microsoft.com and give the link for every function you use.

Expectations:
1. The expression on one line, ready to copy.
2. An explanation from the inside out, one line per function.
3. The expected result for my sample value.
4. One edge case where the expression fails, for example an empty value, and how I catch it.

    No add-on license in Microsoft Copilot Chat. The flow itself is covered by Power Automate licenses. Without a copy button: select the text and copy it with Ctrl+C.

    How to use it

    1. Enter the task and a real sample value from the flow run history, without customer data.
    2. Send it and read up on the linked functions in the reference.
    3. Try the expression in a test flow first.
    4. Trigger the edge case on purpose and check whether your handling catches it.

    How to spot a good answer

    • An expression on one line.
    • One line of explanation per function, from the inside out.
    • A link to the reference for every function.
    • One edge case with a solution.

    The check

    Measure the time until you have a working expression. Then count the flow runs per month that fail because of expression errors.

    Limits

    • According to Microsoft, the expression functions reference applies to Azure Logic Apps and to Power Automate. It is part of the Azure Logic Apps documentation.
    • For time zones, the reference points to the Windows time zone names. Check the result on a date in summer and on one in winter.
    • No connection data, keys or customer data in the prompt. According to Microsoft, web search queries are not covered by the Data Protection Addendum.
    • If web search is turned off, the links are missing. Then you look up the functions yourself.
    • The flow itself is covered by Power Automate licenses. Those are not checked here.

    Sources

    Microsoft Learn: Reference guide to functions in expressions for workflows in Azure Logic Apps and Power Automate, Microsoft Learn: Enterprise data protection in Microsoft Copilot and Microsoft Copilot Chat, Microsoft Learn: Manage Microsoft Copilot Chat. As of October 15, 2026.
