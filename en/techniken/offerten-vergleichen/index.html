    The Quote DuelCompare several quotes

    When several quotes are on the table

    The situation

    Three vendors, three PDFs, three different layouts. The lowest price is in big letters on page one. What is missing is written nowhere.

    The cut

    Before

    “Which quote is the best?”

    After

    Make it yours

    Nothing leaves your browser.

    e.g. the new phone system

    Prompt to copy

    Goal: Compare the attached quotes for [Service, e.g. the new phone system]. Do not decide for me.

Source: Only the attached files. If a quote is missing a detail, write “missing”. Do not guess.

Expectations:
1. A comparison table. The columns are the vendors. The rows are: total price, price components, scope of services, delivery time, payment terms, warranty, contract term and termination, exclusions.
2. Differences that only show up at second glance, for example services only one vendor includes.
3. For each vendor, the questions I should ask before deciding.
For every number, give the location, with file and page.

    No add-on license, in Microsoft Copilot Chat with file upload. Without a copy button: select the text and copy it with Ctrl+C.

    How to use it

    1. Upload all quotes as files to Microsoft Copilot Chat.
    2. Fill in the service and send.
    3. Note every row marked “missing” as a question for the vendor.
    4. Recalculate totals and prices yourself before you decide.

    How to spot a good answer

    • A table with all vendors as columns.
    • “missing” instead of estimated values.
    • A location with file and page for every number.
    • Questions for each vendor.

    The check

    Count the questions to vendors that you would not have asked without the table.

    Limits

    • Recalculate totals yourself. The table is a reading aid, not an audit.
    • According to Microsoft, file uploads have limits. The pages we checked give no numbers.
    • Only upload third-party quotes if your internal rules allow it.
    • You have to decide yourself. The prompt deliberately rules out a recommendation.

    Sources
