    The belt path

    Seven belts. From the first clean prompt to an agent in production.

    1. White belt: Ready stance4 techniques

      What you can do afterwards: Write prompts with Goal, Context, Source and Expectations, and get interviewed before you write.

    2. Yellow belt: Second look4 techniques

      What you can do afterwards: Request and check drafts so that errors show up before you send them.

    3. Orange belt: Tracking5 techniques

      What you can do afterwards: Analyze files and web sources, with a source location for every statement.

    The threshold. From here on you build agents. The Copilot Studio trial is enough to practice.

    1. Green belt: First student4 techniques

      What you can do afterwards: Instruct and check your first own agent.

    2. Blue belt: Sequence3 techniques

      What you can do afterwards: Give an agent steps and define when it hands over to a person.

    3. Brown belt: Budget3 techniques

      What you can do afterwards: Pass data on cleanly and estimate an agent's consumption before it gets expensive.

    4. Black belt: Watch2 techniques

      What you can do afterwards: Monitor agents in production and shut them down in time.
