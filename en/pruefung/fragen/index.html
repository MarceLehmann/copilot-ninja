    Belt exam

    All questions with explanations

    For each belt, the test draws one of these questions. The explanation is below each question. Questions about Microsoft features are valid for 120 days from the check date. After that, the test removes them from the pool until they have been checked again.

    1. White belt

      “Summarize the document. Use only the attached file. No more than five bullet points.” Which of the four elements of an effective prompt is missing?

      • Goal
      • Source
      • Expectations
      • Context
      Answer

      The correct answer is: Context

      Microsoft names Context, Goal, Source and Expectations. What is missing here is what it is for and who it is for.

      Source: Microsoft Learn, training module “Write effective prompts”, as of October 13, 2026.

    2. White belt

      Which four elements does the Microsoft training module name for an effective prompt?

      • Context, Goal, Source, Expectations
      • Role, tone, length, format
      • Question, example, rule, goal
      Answer

      The correct answer is: Context, Goal, Source, Expectations

      Microsoft names Context, Goal, Source and Expectations. Every technique in the Dojo builds on these four parts.

      Source: Microsoft Learn, training module “Write effective prompts”, as of October 13, 2026.

    3. Yellow belt

      You have a draft checked against a source document. Which request gives you the answer that is easiest to verify?

      • “Is everything correct?”
      • A table with statement, location in the source and finding (supported, different, not in the source)
      • “Improve the text.”
      Answer

      The correct answer is: A table with statement, location in the source and finding (supported, different, not in the source)

      With the location and a fixed finding for each statement, you see line by line what is supported, what differs and what is missing from the source. If you ask “Is everything correct?”, you usually just get a yes.

      From technique 6, The Hawk Eye.

    4. Yellow belt

      The answer marks a statement from your draft as “supported”. What does that mean for you?

      • It is definitely correct.
      • It is a hint. You look up two of the hits in the source yourself.
      • You do not need to check anything else.
      Answer

      The correct answer is: It is a hint. You look up two of the hits in the source yourself.

      A “supported” is a hint, not a certainty. If you look up two hits yourself, you quickly see how far you can trust the check.

      From technique 6, The Hawk Eye.

    5. Orange belt

      Are web search queries from Microsoft Copilot Chat covered by the same data protection commitment as your prompts and responses?

      • Yes, everything is protected the same way.
      • No, they run separately through Bing with their own data rules.
      • Copilot Chat has no web search.
      Answer

      The correct answer is: No, they run separately through Bing with their own data rules.

      According to Microsoft, Enterprise Data Protection applies to prompts and responses. Web search queries go to the Bing service, run under their own data rules and, according to Learn, are not covered by the Data Protection Addendum. That is why customer names and internal figures do not belong in a research question.

      Source: Microsoft Learn, Enterprise Data Protection, as of October 13, 2026.

    6. Orange belt

      Can Microsoft Copilot Chat analyze uploaded files without an add-on license?

      • Yes, file upload is included, with limits that have no published numbers.
      • No, only with a license.
      • Only images.
      Answer

      The correct answer is: Yes, file upload is included, with limits that have no published numbers.

      According to Microsoft, “upload and analyze files” is part of Copilot Chat without an add-on license. File uploads have limits, but Learn does not give specific numbers on this page.

      Source: Microsoft Learn, Copilot Chat Overview, as of October 13, 2026.

    7. Orange belt

      You have research done on the web. Which request lets you verify what is true?

      • “Summarize the topic thoroughly.”
      • After every sentence the link it comes from, plus a separate list “Not supported”.
      • “Use only reputable sources.”
      Answer

      The correct answer is: After every sentence the link it comes from, plus a separate list “Not supported”.

      Without a link for each sentence, you cannot verify anything, and assumptions get mixed in with evidence.

      From technique 12, The Trail.

    8. Green belt

      An agent in Microsoft Copilot Chat uses only instructions and public websites. What does it cost without an add-on license?

      • It is billed by consumption.
      • It is included at no extra cost.
      • It needs a Copilot Studio license.
      Answer

      The correct answer is: It is included at no extra cost.

      According to Microsoft, agents that rely only on instructions and public websites are included at no extra cost. They have no access to your organization's data.

      Source: Microsoft Learn, Agents in Copilot Chat, as of October 13, 2026.

    9. Green belt

      An agent in Microsoft Copilot Chat should access documents in SharePoint. What applies without a license?

      • No extra cost, active right away.
      • Billed by consumption, off by default for Copilot Chat users.
      • Not possible.
      Answer

      The correct answer is: Billed by consumption, off by default for Copilot Chat users.

      According to Microsoft, agents with access to your organization's data, for example from SharePoint, are billed by consumption and are off by default for Copilot Chat users. The admins set up a Copilot Studio subscription or pay-as-you-go for this.

      Source: Microsoft Learn, Agents in Copilot Chat, as of October 13, 2026.

    10. Blue belt

      Your instruction requires the agent to use a tool that is not set up in the agent. What happens?

      • The agent sets it up itself.
      • It cannot follow the instruction.
      • It looks for a similar tool.
      Answer

      The correct answer is: It cannot follow the instruction.

      According to Microsoft, an agent can only follow instructions about tools, knowledge sources, agents or topics if they are set up in the agent.

      Source: Microsoft Learn, Instructions in Copilot Studio, as of October 13, 2026.

    11. Blue belt

      Should you change or suppress your agent's citation format through an instruction?

      • Yes, that is common.
      • No, Microsoft advises against it.
      • Only for internal agents.
      Answer

      The correct answer is: No, Microsoft advises against it.

      Microsoft advises not to change or suppress the system citation format through instructions.

      Source: Microsoft Learn, Instructions in Copilot Studio, as of October 13, 2026.

    12. Brown belt

      Can you publish an agent in the free trial of Copilot Studio?

      • Yes.
      • No. Building and checking in the test chat, yes. Publishing, no.
      • Only in Teams.
      Answer

      The correct answer is: No. Building and checking in the test chat, yes. Publishing, no.

      According to Microsoft, the trial license lets you create agents and check them in the test chat. Publishing is not possible with it.

      Source: Microsoft Learn, Copilot Studio licenses and subscriptions, as of October 13, 2026.

    13. Brown belt

      According to Microsoft, how many Copilot Credits does one Generative Answer in Copilot Studio consume?

      • 1
      • 2
      • 10
      Answer

      The correct answer is: 2

      Classic Answer 1, Generative Answer 2, Agent Action 5, Tenant Graph Grounding 10 Copilot Credits. The rates can change.

      Source: Microsoft Learn, Copilot Credits and capacity, as of October 13, 2026.

    14. Black belt

      Without pay-as-you-go on the environment, what happens at 125 percent of prepaid Copilot Credits capacity?

      • Nothing, the extra is billed afterwards.
      • Custom agents are disabled, ongoing conversations are not interrupted.
      • All agents stop immediately.
      Answer

      The correct answer is: Custom agents are disabled, ongoing conversations are not interrupted.

      Overage is tolerated between 100 and 125 percent. From 125 percent, custom agents are disabled. Ongoing conversations finish; subsequent calls are rejected until capacity is increased or reset. With pay-as-you-go on the environment there is no enforcement; overage is billed to Azure.

      Source: Microsoft Learn, Copilot Credits and capacity, as of October 13, 2026.

    15. Black belt

      Does the Copilot Studio test panel reproduce all behavior of published channels?

      • Yes.
      • No, it is meant for checking while you build.
      • Only for Teams.
      Answer

      The correct answer is: No, it is meant for checking while you build.

      According to Microsoft, the test panel is meant for checking while you build and does not reproduce all behavior of published channels.

      Source: Microsoft Learn, Test your agent in the test panel, as of October 13, 2026.
