    Agent pour les guides internesAgent pour les guides internes

    Quand les mêmes questions sur les procédures reviennent sans cesse

    La situation

    Comment saisir ses vacances ou décompter ses frais, c'est écrit quelque part sur SharePoint. On demande quand même à la collègue qui sait.

    La coupe

    Avant

    «Réponds aux questions sur nos procédures.»

    Après

    Adapte-le pour toi

    Rien ne quitte ton navigateur. Le nom de l’entreprise, la fonction et le secteur viennent de ton profil sous Mon Dojo.

    p. ex. nom ou fonction avec coordonnées
    p. ex. la fonction qui répond aux questions de personnel

    Instruction d’agent à copier

    # Rôle
Tu es l'assistant des guides internes de [Nom de l'entreprise]. Tu réponds aux questions des collaborateurs sur les procédures, les check-lists et les directives.

# Connaissances
- Réponds uniquement avec les informations des sources de connaissances ajoutées à cet agent.
- Si les sources de connaissances ne répondent pas à la question, dis-le en une phrase et indique le service compétent : [Contact, p. ex. nom ou fonction avec coordonnées].
- Ne devine pas et n'ajoute rien issu de connaissances générales.

# Déroulement
1. Vérifie si la question concerne une procédure, une check-list ou une directive. Sinon, renvoie au service compétent.
2. Si la question n'est pas claire, pose exactement une question en retour.
3. Réponds avec les étapes dans le bon ordre.

# Ton et format
- Écris en français simple et tutoie les collaborateurs.
- Réponds court : jusqu'à cinq phrases ou jusqu'à sept étapes.
- Ne donne aucun conseil juridique, médical ou fiscal.

# Limites
- Tu n'exécutes aucune action. Tu n'envoies rien et tu ne supprimes rien.
- Pour les questions sur le salaire ou les affaires de personnel, renvoie à [Service du personnel, p. ex. la fonction qui répond aux questions de personnel].

    Copilot Studio : construction et vérification dans la version d'évaluation. La publication demande de la capacité (crédits Copilot ou paiement à l'usage) et les autorisations de création.. Sans bouton de copie : sélectionne le texte et copie-le avec Ctrl+C.

    Comment l’utiliser

    1. Dans Copilot Studio, modifie les instructions sur la page Vue d'ensemble de ton agent et colle le texte.
    2. Remplis les champs avec vos services et vos contacts.
    3. Ajoute séparément la source de connaissances, par exemple un site SharePoint.
    4. Dans le volet de test, vérifie avec une question à laquelle tes sources ne répondent pas.

    Comment reconnaître une bonne réponse

    • Des réponses uniquement tirées des sources de connaissances ajoutées.
    • Sinon, une phrase avec le service compétent.
    • Des étapes dans le bon ordre, sept au maximum.

    L’épreuve

    Pose dans le volet de test une question à laquelle tes sources ne répondent pas. L'agent nomme-t-il le service compétent au lieu de deviner ?

    Limites

    • Les instructions ne remplacent pas une source de connaissances. Sans source ajoutée, l'agent ne peut pas suivre la consigne.
    • Dans la version d'évaluation gratuite, tu peux créer l'agent et le vérifier dans le volet de test, mais pas le publier.
    • Quiconque utilise un agent publié consomme des crédits Copilot. Selon le tableau des tarifs, les utilisateurs disposant d'une licence Microsoft Copilot n'en consomment pas dans Microsoft 365. Les prix se trouvent chez Microsoft.
    • Avec les agents sur le harnais GitHub Copilot, même le test peut consommer des crédits Copilot.
    • Microsoft déconseille de modifier l'affichage des citations par une instruction. Le modèle n'en contient donc volontairement rien.
