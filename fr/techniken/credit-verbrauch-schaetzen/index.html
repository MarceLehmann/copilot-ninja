    La boussole des créditsEstimer à l'avance la consommation de crédits d'un agent

    Avant qu'un agent passe en production

    La situation

    La direction demande ce que le nouvel agent consomme en exploitation. Tu as une intuition, mais pas de calcul.

    La coupe

    Avant

    «Combien coûte mon agent?»

    Après

    Adapte-le pour toi

    Rien ne quitte ton navigateur.

    p. ex. collaborateurs du service interne
    p. ex. une source de connaissances et deux outils
    p. ex. les instructions de ton agent

    Texte à copier

    Objectif : Aide-moi à estimer pour mon agent les événements par conversation. Ses instructions figurent ci-dessous.

Contexte : L'agent est destiné à [Public cible, p. ex. collaborateurs du service interne]. Il utilise [Équipement, p. ex. une source de connaissances et deux outils].

Attentes :
1. Pour une conversation typique et pour une longue : combien de réponses issues de sources de connaissances (génératives), combien de réponses prédéfinies (classiques), combien d'actions comme des outils ou des changements entre rubriques et combien d'étapes dans des flux d'agent sont à prévoir.
2. Une phrase de justification par chiffre.
3. L'hypothèse qui modifie le plus le résultat.
Indique tout comme estimation. Ne calcule aucun prix.

Instructions :
[Instructions, p. ex. les instructions de ton agent]

    Calculer sans licence, l'exploitation demande de la capacité. Sans bouton de copie : sélectionne le texte et copie-le avec Ctrl+C.

    La boussole

    Tarifs selon Microsoft dans crédits Copilot : Réponse classique 1, Réponse générative 2, Action d'agent 5, Ancrage dans le graphe du locataire 10, Action de flux d'agent 0.13.

    Exemple de calcul : 400 conversations par mois, chacune avec 3 réponses génératives et 1 action d’agent, donnent 400 fois 11, soit 4 400 crédits Copilot. Hypothèse inventée pour illustrer.

    • Selon la page sur les licences, Copilot Studio applique la capacité achetée chaque mois, et les crédits Copilot non utilisés ne sont pas reportés au mois suivant. L'Agent Usage Estimator écrit en revanche que certains achats sont reportables. C'est ton contrat qui fait foi.
    • Selon la page Learn «Taux de facturation et gestion», un dépassement est toléré jusqu'à 125 pour cent de la capacité prépayée ; à partir de 125 pour cent, les agents sont bloqués jusqu'à ce que la capacité soit augmentée ou réinitialisée ; avec le paiement à l'utilisation sur l'environnement, le dépassement est facturé à l'abonnement Azure. La page d'administration sur les crédits Copilot ajoute : sans source de dépassement (paiement à l'utilisation ou pool du locataire), un environnement ne consomme que son allocation, et les fonctions qui demandent des crédits peuvent s'arrêter ensuite. Les deux sources sont liées ci-dessous.
    • Pour les flux d'agent, des règles de capacité propres s'appliquent : s'il n'y a plus de crédits Copilot disponibles, aucune nouvelle exécution de flux ne démarre, l'agent continue selon Microsoft de répondre pour les autres interactions.

    Avec la case cochée, le calculateur ne met à 0 crédit que les réponses classiques, les réponses génératives et l'ancrage dans le graphe du locataire, lorsque l'agent fonctionne avec l'identité connectée d'un utilisateur disposant d'une licence complémentaire Microsoft 365 Copilot. Des limites d'utilisation équitable s'appliquent. Les actions d'agent et les actions de flux d'agent restent incluses par précaution. Les actions d'agent d'utilisation de l'ordinateur ne sont pas gratuites d'office. Vérifie dans la source Microsoft les exceptions qui s'appliquent à ton cas.

    Source : Microsoft Learn : Taux de facturation et gestion (Copilot Studio), Microsoft Learn : Licence standard pour harnais (Copilot Studio), Microsoft Learn : Estimateur d'utilisation de l'agent (Copilot Studio), Microsoft Learn : Gérer les crédits Copilot et la capacité pour Copilot Studio (Power Platform admin center), état au 15 octobre 2026. Pas de prix par crédit, les prix se trouvent chez Microsoft.

    Comment l’utiliser

    1. Colle les instructions, décris le public cible et l'équipement, et envoie dans Microsoft Copilot Chat.
    2. Reporte les chiffres par conversation dans le calculateur de cette page et estime les conversations par mois.
    3. Calcule trois cas : peu, moyennement et beaucoup d'exploitation.
    4. Pour une estimation plus précise, Microsoft propose l'Agent Usage Estimator.
    5. Après le premier mois, compare la consommation dans le Power Platform Admin Center avec ton estimation.

    Comment reconnaître une bonne réponse

    • Des chiffres pour une conversation typique et une longue.
    • Une justification par chiffre.
    • L'hypothèse qui pèse le plus.
    • Aucun prix, seulement des événements.

    L’épreuve

    Compare ton estimation après le premier mois avec la consommation réelle. L'écart montre à quel point tes hypothèses sur les conversations étaient bonnes.

    Limites

    • Cette page n'indique pas de prix par crédit Copilot. Ils figurent chez Microsoft.
    • Les taux viennent de la documentation Microsoft et peuvent changer. La source liée fait foi.
    • Pour les agents créés dans Agent Builder et qui n'utilisent pas l'ancrage dans le graphe du locataire, aucun crédit n'est facturé selon Microsoft pour les réponses génératives.
    • Microsoft facture les flux d'agent séparément : 13 crédits Copilot pour 100 actions de flux. Selon Microsoft, les flux cloud Power Automate passent par la licence Power Automate et non par les crédits Copilot.
    • Pour l'Agent Usage Estimator, Microsoft recommande une réserve de 10 à 20 pour cent sur l'estimation.
    • L'estimation ne remplace pas le regard sur la consommation réelle.
    • Les coûts supplémentaires, par exemple pour l'accès aux données, les licences ou d'autres services, ne sont pas inclus dans le calculateur.
