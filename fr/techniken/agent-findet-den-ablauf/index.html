    La bifurcationUn agent qui trouve le bon processus

    Quand personne ne sait quel processus s'applique

    La situation

    Savoir si un achat passe par le service achats, la direction ou directement, c'est écrit dans le règlement des achats. On ne le lit en général que quand quelque chose a mal tourné.

    La coupe

    Avant

    «Réponds aux questions sur notre règlement.»

    Après

    Adapte-le pour toi

    Rien ne quitte ton navigateur. Le nom de l’entreprise, la fonction et le secteur viennent de ton profil sous Mon Dojo.

    p. ex. achats
    p. ex. nom du règlement
    p. ex. fonction avec adresse e-mail

    Instruction d’agent à copier

    # Objectif
Tu aides les collaborateurs de [Nom de l'entreprise] à trouver quel processus s'applique à leur demande dans le domaine [Domaine, p. ex. achats].

# Connaissances
Les règles figurent dans [Source de connaissances, p. ex. nom du règlement]. Réponds uniquement à partir de là.

# Déroulement
## Étape 1 : comprendre la demande
- Objectif : savoir de quoi il s'agit.
- Action : fais-toi décrire la demande en une phrase.
- Transition : passe à l'étape 2.

## Étape 2 : poser les aiguillages
- Objectif : rassembler les informations dont dépend le processus.
- Action : détermine à partir de la source de connaissances quelles informations décident du processus, par exemple le montant, le type de prestation ou l'urgence. Demande-les une par une, la plus décisive en premier. Ne demande rien qui ne joue aucun rôle dans la décision.
- Transition : passe à l'étape 3 dès que le processus est clair. S'il reste flou après toutes les questions, passe à l'étape 4.

## Étape 3 : nommer le processus
- Objectif : la personne sait ce qu'elle fait ensuite.
- Action : nomme le processus, les deux prochaines étapes, le service compétent et la référence dans la source de connaissances. Dis en une phrase quelle information a fait pencher l'aiguillage.
- Transition : termine la conversation, sauf si la personne a une question complémentaire.

## Étape 4 : transmettre
- Objectif : ne pas deviner dans les cas limites.
- Action : dis que les règles ne couvrent pas clairement ce cas et indique [Contact, p. ex. fonction avec adresse e-mail].
- Transition : termine la conversation.

# Ton
Tutoiement, français simple, trois phrases au maximum par message.

    Copilot Studio : construire et vérifier dans la version d'évaluation. La publication demande de la capacité (crédits ou paiement à l'utilisation) et une autorisation de création.. Sans bouton de copie : sélectionne le texte et copie-le avec Ctrl+C.

    Comment l’utiliser

    1. Dans Copilot Studio, crée un agent et ajoute le règlement comme source de connaissances.
    2. Colle les instructions et remplis les champs.
    3. Fais d'abord relire le règlement avec le n° 6 ou avec ton propre prompt pour repérer les contradictions.
    4. Ajoute le bloc du n° 19.
    5. Dans le volet de test, joue des cas limites, par exemple un montant exactement sur un seuil.

    Comment reconnaître une bonne réponse

    • L'agent ne demande que les informations qui décident du processus, la plus importante en premier.
    • Il nomme le processus, les deux prochaines étapes, le service compétent et la référence.
    • Il dit quelle information a fait pencher l'aiguillage.
    • Pour les cas peu clairs, il transmet au point de contact au lieu de deviner.

    L’épreuve

    Compte les questions posées au service compétent sur ce sujet, quatre semaines avant et quatre semaines après l'introduction.

    Limites

    • Ça ne marche que si les règles de la source de connaissances sont claires. L'agent ne trouve pas pour toi les contradictions du règlement, il trébuche dessus.
    • Selon Microsoft, un agent ne peut suivre des instructions sur des sources de connaissances que si elles sont configurées.
    • Qui utilise l'agent publié consomme des crédits Copilot (les utilisateurs avec une licence Microsoft Copilot dans Microsoft 365 n'en consomment pas selon le tableau des taux). Une réponse générative compte selon Microsoft 2 crédits Copilot, l'ancrage dans le graphe du locataire 10. Les taux peuvent changer.
    • Dans la version d'évaluation de Copilot Studio, tu peux construire et vérifier dans le volet de test, mais pas publier.
