    L'empreinteTransformer ton meilleur chat en agent

    À la fin d'un chat qui s'est très bien passé

    La situation

    Dans un chat, tout a enfin été juste après plusieurs corrections. La semaine prochaine, tu repars de zéro et tu expliques tout une fois de plus.

    La coupe

    Avant

    «Retiens comment je veux ça.»

    Après

    Texte à copier

    Objectif : Cette conversation a bien fonctionné. Crée-en trois sections clairement séparées pour un agent.

Source : Uniquement cet historique de chat.

Attentes :
# Nom
30 caractères au maximum.
# Description
1000 caractères au maximum. Décris l'objectif et les tâches de façon que le modèle et les utilisateurs trouvent l'agent.
# Instructions
8000 caractères au maximum, en Markdown avec les sous-titres Objectif, Déroulement, Ton et format, ainsi que Limites. Chaque étape du déroulement avec objectif, action et transition vers l'étape suivante. Reprends mes corrections comme règles fixes. Laisse de côté les détails qui ne valaient que pour ce cas précis et liste-les séparément après les trois sections.

    Avec Agent Builder sans frais supplémentaires, uniquement des instructions et des sites web publics ; l'activation dépend selon Microsoft de la licence ou du paiement à l'utilisation. Sans bouton de copie : sélectionne le texte et copie-le avec Ctrl+C.

    Comment l’utiliser

    1. À la fin d'un chat réussi dans Microsoft Copilot Chat, colle le texte et envoie.
    2. Lis la liste des détails et ajoute ce qui est finalement une règle fixe.
    3. Dans Agent Builder, crée un nouvel agent et va directement à la configuration avec «Ignorer pour configurer».
    4. Dans l'onglet «Configurer», colle le nom dans «Nom» (30 caractères au maximum), la description dans «Description» (1000 caractères au maximum) et seulement les instructions dans «Instructions» (8000 caractères au maximum). «Connaissances» et les invites suggérées sont des champs séparés.
    5. Essaie l'agent dans l'onglet «Essayer» avec trois vraies tâches.
    6. Vérifie ensuite les instructions avec le n° 17.

    Comment reconnaître une bonne réponse

    • Trois sections séparées : nom, description et instructions avec objectif, déroulement, ton et format, ainsi que limites.
    • Chaque étape du déroulement avec objectif, action et transition.
    • Tes corrections comme règles fixes.
    • Une liste séparée des détails qui ne valaient que pour ce cas.

    L’épreuve

    Compte pendant une semaine combien de fois tu tapes la même explication dans un nouveau chat. Compte ensuite une semaine avec l'agent.

    Limites

    • Selon Microsoft, les agents avec des instructions et des connaissances web n'entraînent pas de frais supplémentaires. Pouvoir ouvrir Agent Builder n'est pas documenté de façon uniforme : le guide d'administration sur les agents mentionne comme condition une licence Microsoft 365 Copilot ou le paiement à l'utilisation pour Copilot Studio. Demande à ton service informatique si Agent Builder est activé chez vous.
    • Si l'agent doit accéder à SharePoint ou à d'autres données de l'entreprise, il est facturé selon la consommation, d'après Microsoft. Pour les utilisateurs de Microsoft Copilot Chat, c'est désactivé par défaut.
    • Les noms de menu viennent de la documentation Microsoft. Dans ton interface, ils peuvent s'appeler autrement.
    • Un historique de chat montre un cas. Essaie l'agent avec d'autres cas avant de le partager.

    Sources

    Microsoft Learn : Choisissez entre Agent Builder et Copilot Studio pour créer votre agent, Microsoft Learn : Acheter et gérer des agents dans Copilot Chat, Microsoft Learn : Créer des agents dans Agent Builder, Microsoft Learn : Rédiger des instructions efficaces pour les agents déclaratifs.
