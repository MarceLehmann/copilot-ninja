    Le rapport d'éclaireurQu'ai-je manqué pendant mes vacances

    Le premier jour après les vacances

    La situation

    Après les vacances, la boîte de réception est pleine et les discussions Teams ont continué sans toi. Tu lis d'abord ce qui est en haut, pas ce qui est important.

    La coupe

    Avant

    «Qu'est-ce que j'ai manqué?»

    Après

    Adapte-le pour toi

    Rien ne quitte ton navigateur.

    p. ex. date
    p. ex. date

    Prompt à copier

    Objectif : J'ai été absent du [Début de l'absence, p. ex. date] au [Fin de l'absence, p. ex. date]. Fais-moi un rapport de situation pour que je sache par où commencer.

Source : Mes e-mails, mes conversations Teams et mes réunions de cette période.

Attentes :
1. Ce qui attend une réponse de ma part, avec l'expéditeur et la date, les plus anciens d'abord.
2. Les décisions prises sans moi.
3. Les rendez-vous des cinq prochains jours ouvrés qui demandent une préparation.
4. Ce que je peux ignorer, avec une courte justification.
Cite la source pour chaque point. Si tu n'es pas sûr d'un classement, dis-le.

    Avec licence. Limité sans licence dans Outlook. Sans bouton de copie : sélectionne le texte et copie-le avec Ctrl+C.

    Comment l’utiliser

    1. Avec une licence Microsoft Copilot : colle le prompt, renseigne les dates, envoie.
    2. Sans licence : ouvre Microsoft Copilot Chat dans Outlook. Selon Microsoft, il y prend en compte la boîte de réception, le calendrier, les réunions, les conversations et un ensemble limité de fichiers, dans une moindre mesure qu'avec une licence.
    3. Pour chaque point sous «attend une réponse», ouvre la source avant de répondre.
    4. Parcours une fois la liste «je peux ignorer» avant de vraiment l'ignorer.

    Comment reconnaître une bonne réponse

    • Quatre sections dans l'ordre demandé.
    • Pour chaque point, une source que tu peux ouvrir.
    • Les classements incertains sont marqués comme incertains.

    L’épreuve

    Mesure le temps entre la première connexion après les vacances et la première réponse envoyée, et compare-le avec ton dernier retour.

    Limites

    • Selon Microsoft, la réponse ne voit que les contenus auxquels tu as de toute façon accès. Ce qui ne figure ni dans la boîte de réception ni dans une conversation manque aussi dans le rapport.
    • Les accords oraux sans note n'apparaissent pas.
    • «Je peux ignorer» est une proposition, pas une décision.
    • Sans extension, il n'y a pas d'accès large aux données de l'organisation. Les exceptions sont Copilot Chat dans Outlook dans les scénarios pris en charge, les contenus importés ou collés et les agents avec accès autorisé.
