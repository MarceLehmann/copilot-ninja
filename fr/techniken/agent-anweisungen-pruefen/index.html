    L'essai d'écritureVérifier les instructions d'agent avant le test

    Avant de tester un agent pour la première fois

    La situation

    Les instructions de ton agent ont grossi au fil des semaines. Dans le volet de test, il tourne en rond, et tu ne sais pas quelle règle est en cause.

    La coupe

    Avant

    «Mes instructions d'agent sont-elles bonnes?»

    Après

    Adapte-le pour toi

    Rien ne quitte ton navigateur.

    p. ex. les instructions de ton agent

    Prompt à copier

    Objectif: Vérifie les instructions d'agent ci-dessous avant que je les essaie. Ne les réécris pas.

Attentes: Vérifie ces points et donne un tableau avec référence, problème et proposition.
1. Contradictions entre deux règles.
2. Renvois à des outils, des sources de connaissances, des rubriques ou d'autres agents. Liste-les tous, pour que je vérifie s'ils sont vraiment configurés dans l'agent.
3. Étapes sans transition claire vers l'étape suivante.
4. Mots ambigus comme «court», «parfois» ou «important», qu'un agent peut interpréter de différentes manières.
5. Instructions qui modifient ou suppriment l'affichage des sources ou des citations.
6. Ce que l'agent doit faire quand il ne sait pas comment continuer. Si cela manque, dis-le.
À la fin: les trois points que je devrais corriger en premier.

Instructions:
[Instructions, p. ex. les instructions de ton agent]

    Sans licence supplémentaire dans Microsoft Copilot Chat, pour des instructions issues de Copilot Studio ou d'Agent Builder. Sans bouton de copie: sélectionne le texte et copie-le avec Ctrl+C.

    Comment l’utiliser

    1. Copie les instructions de ton agent, colle-les et envoie-les dans Microsoft Copilot Chat.
    2. Compare la liste des outils et des sources de connaissances avec ce qui est vraiment configuré dans l'agent.
    3. Corrige les trois points les plus importants, puis vérifie l'agent avec le n° 18.
    4. Intègre les modifications une par une et teste entre chaque. C'est ce que Microsoft conseille pour les instructions dans Copilot Studio.

    Comment reconnaître une bonne réponse

    • Un tableau avec référence, problème et proposition.
    • Une liste complète de tous les outils et sources de connaissances mentionnés.
    • Trois points prioritaires à la fin.
    • Aucune instruction réécrite.

    L’épreuve

    Compte les questions de test réussies du n° 18 avant et après la correction.

    Limites

    • Selon Microsoft, un agent ne peut suivre des instructions sur des outils, des sources de connaissances, des agents ou des rubriques que s'ils sont configurés dans l'agent. Le point 2 du prompt le rend justement visible.
    • Microsoft déconseille de modifier ou de supprimer le format des citations dans Copilot Studio par des instructions. Le point 5 repère ces passages.
    • La vérification ne lit que du texte. Seul le test montre si l'agent se comporte ensuite correctement.
    • N'insère des noms internes et des coordonnées dans les instructions que si vos règles internes l'autorisent.

    Sources

    Microsoft Learn: Écrire des instructions d'agent (Copilot Studio), Microsoft Learn: Configurez des instructions de haute qualité pour l'orchestration générative (Copilot Studio), Microsoft Learn: Rédiger des instructions efficaces pour les agents déclaratifs. État au 15 octobre 2026.
