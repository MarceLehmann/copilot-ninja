    Le scribe de l'ombreFixer son propre style d'écriture dans un profil de style

    Quand le brouillon sonne comme une brochure

    La situation

    Les brouillons sont corrects, mais ils sonnent comme une brochure. Tu réécris une phrase sur deux jusqu'à ce qu'elle sonne comme toi.

    La coupe

    Avant

    «Écris ça dans mon style.»

    Après

    Adapte-le pour toi

    Rien ne quitte ton navigateur.

    p. ex. un e-mail aux clientes et clients
    p. ex. le profil de style de l'étape 1 avec toutes les règles et phrases d'exemple
    p. ex. ce qui doit figurer dans le texte

    Texte à copier

    Objectif : Crée à partir des textes joints un profil de style qui permette à quelqu'un d'autre d'écrire comme moi.

Source : Uniquement les textes joints. Ce sont des textes de moi que je trouve réussis.

Attentes : Douze règles au maximum, chacune avec une phrase d'exemple tirée de mes textes. Couvre : longueur des phrases, adresse, entrée en matière, conclusion, mots que j'utilise souvent, mots que je n'utilise jamais, traitement des termes techniques.

    Étape 2 : Écrire avec le profil de style

    Objectif : Écris [Type de texte, p. ex. un e-mail aux clientes et clients] sur le sujet [Sujet] d'après mon profil de style.

Source : Uniquement le profil de style et mes mots-clés ci-dessous. N'invente aucun fait.

Attentes : Le texte, puis les deux passages dont tu es le moins sûr qu'ils sonnent comme moi.

Profil de style :
[Profil de style, p. ex. le profil de style de l'étape 1 avec toutes les règles et phrases d'exemple]

Mots-clés :
[Contenu, p. ex. ce qui doit figurer dans le texte]

    Sans licence supplémentaire dans Microsoft Copilot Chat, avec import de fichier. Sans bouton de copie : sélectionne le texte et copie-le avec Ctrl+C.

    Comment l’utiliser

    1. Importe trois à cinq de tes propres textes du même type sous forme de fichiers et envoie l'étape 1.
    2. Lis le profil de style et supprime ce qui n'est pas juste.
    3. Pour chaque nouveau texte, utilise l'étape 2, avec le profil de style et tes mots-clés.
    4. Facultatif : enregistre les règles les plus importantes comme instructions personnalisées. Selon Microsoft, tu les trouves dans les paramètres de Microsoft Copilot Chat sous Personnalisation, si ton service informatique a activé la fonction.
    5. Transmets le profil de style à l'équipe pour que les textes communs sonnent pareil.

    Comment reconnaître une bonne réponse

    • Douze règles au maximum.
    • Pour chaque règle, une phrase d'exemple tirée de tes propres textes.
    • À l'étape 2, deux passages marqués que tu vérifies en priorité.

    L’épreuve

    Compte les modifications que tu apportes à un brouillon, une fois avec et une fois sans profil de style.

    Limites

    • Prends des textes du même type. Si tu mélanges e-mails et articles spécialisés, le profil de style devient flou.
    • N'importe que des textes qui sont vraiment de toi.
    • Selon Microsoft, les instructions personnalisées s'appliquent à toutes tes conversations. Un style pour les e-mails clients ne convient pas à tous les chats.
    • Les noms de menus viennent du module de formation en anglais. Dans ton interface, ils peuvent s'appeler autrement.
    • Les instructions personnalisées sont en préversion. L'admin de ton tenant contrôle l'activation ; la disponibilité peut varier.

    Sources

    Microsoft Learn : Personnaliser Copilot avec la mémoire et des instructions personnalisées (unité de formation), Microsoft Learn : Écrire une invite efficace (unité de formation), Microsoft Learn : Questions fréquentes sur Microsoft Copilot Chat. État au 15 octobre 2026.
