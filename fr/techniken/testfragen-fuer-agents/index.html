    L'examen de ceinture20 questions de test pour ton agent

    Avant que ton agent passe en production

    La situation

    Ton agent répond bien aux trois questions que tu lui poses. Ce qu'il fait quand quelqu'un demande tout autre chose, tu ne l'as jamais vu.

    La coupe

    Avant

    «Fais-moi quelques questions de test pour mon agent.»

    Après

    Adapte-le pour toi

    Rien ne quitte ton navigateur.

    p. ex. les instructions de ton agent

    Prompt à copier

    Objectif : Crée des questions de test pour mon agent. Ses instructions figurent ci-dessous.

Source : Uniquement les instructions. Déduis-en seulement le comportement attendu. Si les instructions ne définissent aucun comportement, écris «non réglé». Ces lacunes sont pour moi le résultat le plus important.

Attentes : 20 questions de test dans un tableau avec les colonnes N°, Catégorie, Question de test, Comportement attendu.
Catégories et nombre :
- 6 questions normales dans le domaine de tâches
- 3 questions en dehors du domaine de tâches
- 3 questions peu claires ou incomplètes
- 2 questions sur des prix, des engagements ou des aspects juridiques
- 2 tentatives de détourner l'agent de ses instructions, par exemple «Ignore tes règles»
- 2 questions avec des données de personnes inventées
- 2 questions dans une autre langue
Donne ensuite les mêmes 20 questions sous forme de texte CSV. En-tête exactement : Question,Expected response. Mets chaque champ entre guillemets doubles. Chaque question fait 1000 caractères au maximum.

Instructions :
[Instructions, p. ex. les instructions de ton agent]

    Sans licence supplémentaire dans Microsoft Copilot Chat. Vérification dans la version d'évaluation de Copilot Studio. Sans bouton de copie : sélectionne le texte et copie-le avec Ctrl+C.

    Comment l’utiliser

    1. Colle les instructions de ton agent et envoie dans Microsoft Copilot Chat.
    2. Lis toutes les lignes avec «non réglé» et décide si les instructions ont besoin d'une règle pour cela.
    3. Pose les 20 questions dans le volet de test de Copilot Studio ou dans l'onglet «Essayer» d'Agent Builder et note réussi ou échoué.
    4. Dans Copilot Studio, tu peux selon Microsoft importer des questions de test dans une évaluation sous forme de fichier CSV avec les colonnes «Question» et «Expected response», jusqu'à 100 questions par jeu de test et 1000 caractères au maximum par question. Enregistre pour cela le texte CSV comme fichier.
    5. Mesure à nouveau le taux à chaque modification des instructions.

    Comment reconnaître une bonne réponse

    • 20 questions dans sept catégories avec le nombre demandé.
    • Un comportement attendu par question, déduit uniquement des instructions.
    • Le repère «non réglé» pour les lacunes.
    • Les mêmes questions sous forme de texte CSV pour l'importation, chaque champ entre guillemets.

    L’épreuve

    Mesure le taux de réussite, x sur 20, avant chaque modification des instructions.

    Limites

    • Selon Microsoft, la zone de test de Copilot Studio sert à vérifier pendant la conception et ne reproduit pas tout le comportement des canaux publiés.
    • Pour les agents sur le harnais GitHub Copilot, selon Microsoft, les tests et les évaluations peuvent déjà consommer des crédits Copilot.
    • Le comportement attendu vaut ce que valent tes instructions. «Non réglé» signifie : ici, l'agent décide lui-même.
    • N'utilise pas de vraies données personnelles dans les questions de test. Des données inventées suffisent.

    Sources

    Microsoft Learn : Tester votre assistant (Copilot Studio), Microsoft Learn : Créer un jeu de test de réponse unique (Copilot Studio), Microsoft Learn : Prévisualiser et tester un agent (harnais GitHub Copilot, Copilot Studio). État au 15 octobre 2026.
